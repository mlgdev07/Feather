# 🪶 Feather

> A lightweight, modern, and open-source word processor — built for distraction-free writing.

**Feather** is an open-source word processor designed around performance, simplicity, and user freedom. Inspired by the familiarity and layout of classic tools like Microsoft Word, Feather cuts out the bloat, startup lag, and complex menus, delivering an instant-launch environment and a silky-smooth writing flow without sacrificing essential formatting tools.

---

## ✨ Features

- ⚡ **Feather-Light:** Minimal memory footprint, near-instant startup, and low resource usage.
- 📝 **Familiar & Clean UI:** Intuitive formatting toolbar, document styling, and distraction-free editing.
- 🔓 **100% Free & Open Source:** Transparent code, privacy-first, zero telemetry or trackers.
- 💾 **Standard Formats:** Open file format support with export options (e.g., Markdown, DOCX, PDF).
- 🌓 **Dark & Light Modes:** Thoughtfully designed themes to reduce eye strain during long writing sessions.
